grad-autofill

Supervised graduate-application filler

The tool runs on your own computer (Python + a browser it opens for you). It is not a website, so it can't run here. This site hosts a practice portal you can point it at to try every step before using it on a real application.

Open the practice application →

Try it

pip install -r requirements.txt
playwright install chromium
cp profile.example.yaml profile.yaml   # fill in, or use test values
python -m grad_autofill practice

Then in the terminal: f to fill a page, +N to approve flagged rows, Enter to fill, next to continue. On the last page, the Submit button stays blocked until you type allow-submit.

The practice pages deliberately include tricky fields: an unstated date format, an inexact dropdown option (“India (IN)”), a demographic question, a certification checkbox and a required question no profile can answer.
